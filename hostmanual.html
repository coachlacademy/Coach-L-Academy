4. Studio Layout

The Host Studio page consists of three main full-screen sections:

  1. WebDJ Window – For audio streaming.
  2. Live Video Window – Embedded Jitsi for video calls with guests.
  3. Schedule Window – Displays upcoming shows.

Use scroll to move between sections. The arrow indicator points to the next window.

5. WebDJ Connection Details

To go live, connect to WebDJ using these details:

  • Icecast Server: coach-l-radio.duckdns.org (or direct IP 46.101.154.220)
  • Port: 8005
  • Mount Name: /
  • Shoutcast: port 8005 (or 8006 for some clients)
  • Password Format: dj_username:dj_password

Detailed setup instructions are available on the AzuraCast Wiki.

6. Going Live on the Air

  1. Log into WebDJ using your host account.
  2. Press the green "Start Streaming" button to go live.
  3. Select the default microphone source.
  4. Press the red "Cue" button next to the mic source to start speaking.
  5. Use headphones only to prevent audio feedback.
  6. Note: there is usually a 10-second delay in the broadcast.
  7. Scroll to the Live Video window and click Join in Browser to appear on video if needed.

7. Monitoring and Interaction

  • Guests will appear in the Live Video window when they join.
  • You can see chat messages from guests and listeners in the Jitsi chat panel.
  • Scroll down to view the Schedule Window for upcoming shows.

8. Exiting the Studio

  1. Press the Exit Studio button at any time to leave.
  2. This will return you to the Coach L Academy homepage.
