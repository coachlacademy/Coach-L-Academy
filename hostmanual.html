4. Studio Layout

The Host Studio page consists of three main full-screen sections:

  1. WebDJ Window – For audio streaming.
  2. Live Video Window – Embedded Jitsi for video calls with guests.
  3. Schedule Window – Displays upcoming shows.

Use scroll to move between sections. The arrow indicator points to the next window.

5. Using WebDJ: Loading Tracks & Players

  1. Log into WebDJ using your host account.
  2. There are two players: Player 1 and Player 2.
  3. Load tracks by dragging them into either Player 1 or Player 2.
  4. Use the green Start Streaming button to go live on the air.
  5. Volume Controls:
    • Each player has its own volume slider – adjust the slider to increase/decrease that player.
    • Keep the other player muted or at low volume while cueing a track.
    • Use the crossfade slider to fade between Player 1 and Player 2 smoothly.
  6. Cueing Tracks:
    • Select the mic or player you want to cue and press the red Cue button next to it.
    • Always monitor through headphones to avoid feedback.
  7. Once ready, gradually fade into the next track using the crossfade slider for smooth transitions.

6. Going Live on the Air

  1. After logging into WebDJ, press the green Start Streaming button.
  2. Select the default microphone source.
  3. Press the red Cue button next to the mic source to speak.
  4. Always use headphones to prevent audio feedback.
  5. Note: there is usually a 10-second delay in the broadcast.
  6. Scroll to the Live Video window and click Join in Browser to appear on video if needed.

7. Monitoring and Interaction

  • Guests will appear in the Live Video window when they join.
  • You can see chat messages from guests and listeners in the Jitsi chat panel.
  • Scroll down to view the Schedule Window for upcoming shows.

8. Exiting the Studio

  1. Press the Exit Studio button at any time to leave.
  2. This will return you to the Coach L Academy homepage.
